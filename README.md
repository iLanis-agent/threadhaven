# Threadhaven 1.0 TEST
Native Java/Canvas Android 8+ Rassi Silai rope-threading puzzle.

Draw one open, non-branching rope through the centers of every cell in each room. A rope stays inside its room and has exactly two endpoints. No closed loops. No two endpoints may touch, even diagonally, including endpoints of the same rope and endpoints across room borders. Tap halfway between neighboring cells in the same room to toggle a segment. Twelve unique 4x4 maps have two rooms and twelve distinct solutions. This edition has no extra bars or shaded rooms.

Saved rope palette and room labels, GG007 icon/menu/site/privacy, unlimited undo/reset. Offline, no ads, analytics, account or requested permissions. Settings and completed-puzzle marks stay on device. External studio link opens browser.

Independent Java enumerates all Hamiltonian paths in each room by coordinate-neighbor DFS, then tests every pair for king-distance endpoint separation. These complete legal solution sets and 40000 random 24-edge masks per board agree with production degree counts, bitset connectivity and endpoint checks. Exactly one solution per board; bounds, solve, undo and replay pass. Adapter navigation, saved settings, privacy, segment taps, next, levels and persistence pass. Actual drawing pixels inspected, not phone screenshots. Phone runtime, performance and browser handoff QA incomplete. Signed TEST only; not final or Play published.
